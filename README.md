Token Launch Radar — ranks 226 pre-token DeFi protocols by the implied value of a future token launch, from a sealed DefiLlama snapshot, with a concrete farm plan for each one. The value model is calibrated from the snapshot's own live-token protocols (median mcap/TVL per category, shrunk to the global median), so every number on the board follows from the data, not from a hardcoded list of names.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
